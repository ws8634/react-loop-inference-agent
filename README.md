# react-loop-inference-agent

## 项目目标
复刻标准ReAct架构，打造思考→行动→观察→再思考的循环式推理智能体，让Agent具备主动推理、根据结果调整行动的能力。

## 建设内容

1. 标准ReAct双循环核心逻辑封装
2. 独立思考模块，生成行动决策思路
3. 行动执行模块，落地思考后的对应操作
4. 结果观察模块，采集行动执行返回信息
5. 循环终止条件判定，完成任务后自动退出循环

## 核心功能点

- 推理+行动闭环循环机制
- 全程思考过程日志留存
- 根据观察结果动态调整下一步行动
- 自定义循环最大次数，防止死循环
- 任务过程可追溯、步骤可复盘
